# ❤️ Until We Meet Again Website

A cute and heartfelt interactive website for long distance couples, built with Next.js and Framer Motion. Filled with beautiful animations, cherished memories, sweet interactions, and a personalized love letter to make your special someone smile until you meet again. ❤️✨

## 🛠 Tech Stack

- ⚛️ **Next.js** – React Framework for building fast UI
- 🎨 **Tailwind CSS** – For modern and responsive styling
- 🎞️ **Framer-Motion** – Smooth entrance and fade animations

## 🖥 Local Setup

To run this project locally, follow these steps:

```bash
# Clone the repository
git clone https://github.com/Anuj579/until-we-meet-website.git

# Navigate into the folder
cd until-we-meet-website

# Install dependencies
npm install

# Start the development server
npm run dev
```
Then open the development URL in your browser to explore the site.

## 🚀 Deploy to Vercel

The easiest way to deploy this Next.js app is using the [Vercel Platform](https://vercel.com/new).

### Option 1: Deploy with Git (Recommended)
1. Push your repository to GitHub, GitLab, or Bitbucket.
2. Go to [Vercel](https://vercel.com) and click **"Add New..."** > **"Project"**.
3. Import your repository. Vercel will automatically detect Next.js and configure the build settings.
4. Click **Deploy**. Your app will be live in seconds!

### Option 2: Deploy with Vercel CLI
```bash
# Install Vercel CLI globally
npm i -g vercel

# Deploy directly from your terminal
vercel
```
